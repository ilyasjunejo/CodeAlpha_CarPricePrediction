# Car Price Prediction

A Python machine-learning project exploring regression models for estimating vehicle prices from vehicle characteristics.

> **Dataset note:** The current script generates a synthetic dataset with 200 rows. Results are for learning and experimentation; they should not be interpreted as real-world market-price predictions.

## Project overview

The script creates a sample dataset, explores feature relationships, preprocesses the data, trains several regression models, and compares their performance on a held-out test set.

### Workflow

1. Generate and inspect synthetic car data.
2. Perform exploratory data analysis (EDA).
3. Encode the categorical brand feature and scale input features.
4. Split the data into training and test sets.
5. Train and compare Linear Regression, Ridge Regression, Random Forest, and Gradient Boosting.
6. Evaluate models using R², mean absolute error (MAE), and root mean squared error (RMSE).
7. Plot model comparisons and feature importance where supported.

## Tech stack

- Python
- pandas and NumPy
- Matplotlib and Seaborn
- scikit-learn

## Run locally

Python 3.10+ is recommended.

```bash
git clone https://github.com/ilyasjunejo/CodeAlpha_CarPricePrediction.git
cd CodeAlpha_CarPricePrediction
python -m venv .venv
```

Activate the environment, then install the dependencies:

**Windows**
```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python car_price_prediction.py
```

**macOS / Linux**
```bash
source .venv/bin/activate
pip install -r requirements.txt
python car_price_prediction.py
```

The script prints data summaries and model metrics, and saves visualizations in the current working directory. Output filenames may differ from older committed images.

## Repository contents

## Learning goals

This project is a practical exercise in regression, train/test splitting, preprocessing, model comparison, evaluation metrics, and communicating results through visualizations.

## Limitations

The dataset is synthetic and the features/prices are generated by rules plus random noise. A strong score on this dataset does not demonstrate performance on real used-car listings. A production version would require a documented real-world dataset, careful leakage checks, a reproducible preprocessing pipeline, and validation on unseen market data.
