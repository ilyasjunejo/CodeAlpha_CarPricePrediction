# Car Price Prediction

A Python machine-learning project focused on regression for estimating vehicle prices from structured features such as year, mileage, horsepower, engine size, brand, and ownership history. This project is designed to practice a realistic end-to-end workflow: data generation, exploratory analysis, preprocessing, model comparison, and honest evaluation.

## Project purpose

This project explores how vehicle attributes can be used to predict a car's price. The script builds a simple predictive pipeline and compares several regression models to understand which approach performs best on the dataset.

## Dataset

The project currently generates a synthetic dataset inside the script. This means the results are educational and meant for learning, not for real-world market valuation. The data includes artificial patterns and random variation to simulate realistic relationships between features and price.

> Important: this is not a real used-car marketplace dataset, and the results should not be interpreted as actual pricing for a dealership or insurance application.

## Workflow

1. Generate or load a car dataset.
2. Inspect the data and basic statistics.
3. Visualize relationships between price and predictor variables.
4. Encode categorical variables and scale numeric features.
5. Split the data into training and test sets.
6. Train and compare several regression models:
   - Linear Regression
   - Ridge Regression
   - Random Forest Regressor
   - Gradient Boosting Regressor
7. Evaluate models using R², MAE, and RMSE.
8. Save plots for exploratory analysis, feature importance, and model comparison.

## Run locally

Python 3.10+ is recommended.

```bash
git clone https://github.com/ilyasjunejo/CodeAlpha_CarPricePrediction.git
cd CodeAlpha_CarPricePrediction
python -m venv .venv
```

Activate the environment, then install the dependencies:

Windows:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python car_price_prediction.py
```

macOS / Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python car_price_prediction.py
```

The script prints summary tables, evaluation metrics, and saves visual outputs in the working directory.
